九、“消息”页面
这个页面专门承载：
通知日志浏览。
不再把日志塞回首页。
页面标题：
消息
标题右边可以显示：
今日 12 条
或简洁筛选按钮。

消息顶部筛选
可以做一排小型纸质标签：
全部
重要
稍后
已过滤
点击切换。
从首页文件夹进入时，要自动切换到对应筛选。

消息列表视觉
参考第一张图右边的 Chats。
不要把每条通知做成完全相同的白色长方形卡片。
可以将消息做成：
柔和彩色消息气泡
或：
彩色纸条式卡片
卡片内至少有：
App / 来源
时间
消息标题
消息摘要
当前分类
如果现有数据中有重要性 / score，也可以以非常轻量的方式显示。
不要把模型内部所有数值都塞进去。
重要消息可用珊瑚红 / 暖黄；
稍后可用淡黄 / 蓝；
已过滤可用淡紫 / 灰蓝；
普通通知使用浅白或浅蓝。
消息卡的形状可以有一点“气泡尾巴”，但不要做得像儿童聊天软件。
一条消息高度控制紧凑。
列表允许正常垂直滚动。
“不能做长首页”并不意味着消息列表不能滚动。
