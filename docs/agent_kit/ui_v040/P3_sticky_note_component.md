十一、便签组件必须怎样画
请实现统一可复用的 PinnedNoteView / NoteCard 方法。
一个完整便签必须至少有：
1. 最底层柔和阴影
2. 厚一点的白色纸板
3. 内部彩色便签纸
4. 顶部立体图钉
5. 编号 / 小标签
6. 主标题
7. 说明文字
图钉位于白纸上边缘附近。
可以模拟参考图：
蓝色图钉
紫色图钉
橙色图钉
图钉实现可以由几个小 View / Drawable 叠加：
底部深色小椭圆阴影
中间圆柱感圆形
顶部较亮圆形
一个很小的高光
这样产生立体感。
每张便签可以旋转：
-1.5°
+1°
-0.8°
等非常小的角度。
不要超过约 2°。
白色底板圆角大约：
16～22dp
内层彩纸比底板四周小：
12～16dp
便签背景可以是：
淡黄
淡蓝
淡紫
淡橙
不要使用普通 Material Card 直接替代。
