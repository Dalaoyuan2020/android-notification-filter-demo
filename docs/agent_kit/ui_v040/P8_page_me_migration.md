十三、“我的”页面
“我的”不是个人社交主页。
它承担：
权限
筛选规则
自动清除
高级设置
使用引导
关于
等低频配置入口。
页面标题：
我的
顶部可以做一张简单身份纸片，例如：
Attention
本地优先的消息辅助工具
不需要头像。
不需要登录。
不要伪造账号体系。

设置入口视觉
不要使用 Android 默认 Settings 长列表。
建议做成：
两组文件夹 / 纸张目录
第一组：
通知权限
筛选规则
第二组：
自动清除
高级设置
使用引导
或者使用简洁的纸条列表。
这里不需要像首页一样每一个都做大型文件夹。
视觉要比首页克制。
已经存在实际入口的必须继续连接。
暂时没有深层功能实现的，可以保留基础 UI 入口或当前原有逻辑，不要虚构已经完成的后台能力。
“使用引导”需要继续能够打开：
OnboardingActivity
