四、整体视觉参考
我给了两张视觉参考图。
参考图 1 的重点
不要照抄图中文字和人物，而是提取下面这些视觉特征：
1.米白色 / 暖白色网格纸背景；
2.很大的黑色页面标题；
3.文件夹不是普通矩形 Card，而是真正有“文件夹结构”的卡片；
4.文件夹上方有凸出的 tab；
5.文件夹内部可以看到露出来的纸张；
6.文件夹使用黄、蓝、紫、绿等低饱和彩色；
7.信息卡片可以像聊天气泡、纸片、文件一样存在；
8.底部导航栏是漂浮的白色圆角工具条；
9.整体年轻、有设计感，但不是儿童卡通；
10.大量留白，不把页面塞满。
参考图 2 的重点
这是这次“便签卡片”最重要的视觉参考。
我要的不是现在那种：
普通 CardView + 一个圆点假装图钉
我要明显具有：
白色厚纸底板
+
内部彩色便签纸
+
顶部立体图钉
+
纸张阴影
+
极轻微旋转
的感觉。
图钉需要有一定立体感，可使用：
多层圆形；
深浅变化；
小阴影；
中心高光；
下方轻微针脚/投影；
来模拟。
不要求真的做 3D 模型，但必须让人一眼看出是一个“钉在纸上的便签”，而不是一个 Material Card。


五、全局视觉规范
整个 App 统一使用一种：
纸张 / 文件夹 / 便签 / 消息气泡式轻拟物 UI。
不是纯 Material Design。
也不是玻璃拟态。
不是深色赛博风。
不是后台 Dashboard。

1. 背景
主背景使用暖白色，例如：
#F7F4EE
或非常接近的颜色。
背景加入非常淡的方格纸纹理。
建议网格间距约：
22dp～28dp
网格线颜色类似：
#E7E1D8
线要非常细、非常浅。
不要让网格抢内容。
如果直接程序绘制网格更方便，可以自定义 Background Drawable / View。

2. 主文字
页面一级标题：
30sp～34sp
字重明显。
颜色接近：
#111111
标题不要放进 Toolbar 色块。
像参考图一样直接“长在纸上”。
正文不要大段居中。
字体优先系统字体，避免额外字体依赖。

3. 页面留白
左右主要边距：
20dp～24dp
标题与正文区域间距清楚。
不要让所有元素贴边。
不要每个模块都套一个大白色圆角 Card。

4. 彩色体系
整体采用低饱和、年轻、柔和颜色。
可以围绕：
暖黄
柔和蓝
珊瑚红
淡紫
薄荷绿
建议近似：
Yellow  #F4C542
Blue    #79AEEF
Coral   #FF7168
Purple  #C5A6E8
Green   #65C99D
可以自行微调。
不允许：
荧光高饱和；
大量渐变；
五颜六色到无法统一；
黑底科技风；
蓝紫霓虹 AI 风。
