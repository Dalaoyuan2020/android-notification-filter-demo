八、文件夹组件必须怎样画
请专门实现一个可复用的 FolderView / FolderCard 构造方法或 UI helper。
一个文件夹至少包含以下视觉层次：
Layer 1
后方白色纸张

Layer 2
文件夹后背板

Layer 3
顶部凸起的 folder tab

Layer 4
中间露出的 1～3 张纸

Layer 5
前方彩色文件夹主体

Layer 6
标题 + 数量
前后一定要有层次。
不能只是顶部画一个小矩形就称为文件夹。
内部露出的纸张可以：
高度不同；
有白色纸；
有非常浅的灰线；
偶尔露出一小块彩色标签。
不需要网络图片，也不需要人物照片。
文件夹建议颜色：
重要消息   暖黄 / 珊瑚
稍后处理   蓝色
已过滤     紫色
通知记录   薄荷绿
文件夹主体要有：
轻微 elevation
下方柔和阴影
12～18dp 圆角
标题放在文件夹正面。
数量使用小号字：
12 条
数量同样来自真实日志。
点击：
重要消息
自动切换到底部：
消息
页面，并直接应用“重要消息”筛选。
另外三个文件夹同理。
所以文件夹不是装饰，必须有实际导航功能。
