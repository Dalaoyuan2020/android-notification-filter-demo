二十二、首次启动动画引导——本轮必须完成
除了四个正式页面之外，本轮必须完善一套：
首次启动使用引导 / Onboarding 动画。
这不是普通的“说明文字页面”，而应该像一个完整产品第一次打开时的 onboarding experience。
用户第一次安装并打开 App 时：
启动 App
↓
首次启动判断
↓
动画引导 OnboardingActivity
↓
点击“开始使用”
↓
进入 MainActivity 首页
第二次以及之后正常启动：
启动 App
↓
直接进入 MainActivity
同时：
我的
→ 使用引导
必须能够随时再次进入完整引导。

1. 不要做成普通静态 PPT
首次引导不能只是：
图片
标题
一段文字
下一步
连续复制 4 页。
我要的是：
轻量、有动效、有产品感的交互式动画引导。
不需要复杂 Lottie，也不要额外引入大型动画库。
优先使用 Android 原生：
ViewPropertyAnimator
ObjectAnimator
AnimatorSet
alpha
translationX
translationY
scaleX / scaleY
rotation
完成。
动画要求流畅、短促。
不要做很慢的开屏动画。

2. 引导整体视觉
引导页必须延续正式 App 的视觉语言：
暖白色网格纸背景
+
文件夹
+
彩色纸张
+
便签
+
图钉
+
消息气泡
所以第一次进入时，用户已经能理解：
这个 App 是一个“帮我整理通知、判断重要性”的智能消息桌面。
不要做成：
蓝紫 AI 科技渐变；
黑色赛博背景；
大脑芯片插画；
发光粒子；
普通 Material Design 三页轮播。

3. 引导建议为 4 幕
整个首次引导建议控制为：
4 个场景
不宜超过 5 页。
整体完成时间：
用户快速点击约 10～15 秒即可完成

第一幕：消息越来越多
页面核心标题：
消息很多，
但你的注意力有限。
或：
不是每一条通知，
都值得现在打断你。
副文案：
Attention 会根据内容与个性化信息，
帮你判断哪些消息值得优先处理。
动画
页面开始时保持相对干净。
然后从屏幕上方依次掉下来 / 滑下来几张小消息纸条：
老师：明天上午把修改后的方案发我

项目群：会议改到下午三点

快递：包裹已放驿站

群聊：晚上吃什么？
注意：
这些只是 onboarding 中的演示内容，与正式页面真实数据不同，可以使用固定示例。
消息纸条不要同时出现。
可以：
第1条 0ms
第2条 120ms
第3条 240ms
第4条 360ms
从：
translationY = -20dp
alpha = 0
进入：
translationY = 0
alpha = 1
最后一刻稍微叠在一起，表现“通知很多”。
总动画时间不要超过约：
800～1200ms

第二幕：智能判断重要性
标题：
先判断，
再决定是否打扰你。
副标题：
Jev 网络结合消息内容与个性化特征，
对通知重要性进行判断。
动画表现
页面中心先出现一张：
白色消息纸条
然后从它附近浮现几个非常轻量的小标签：
来源
内容
时间
个性化
标签通过：
scale 0.85 → 1
alpha 0 → 1
出现。
接着这些小标签轻微向消息纸条中心靠近。
最后弹出一个：
重要
的暖黄色 / 珊瑚色标签。
整体表达：
消息
+
上下文
→
智能判断
不需要画复杂神经网络。
不需要假装展示真实模型计算过程。
这是概念动画。

第三幕：通知自动整理
标题：
重要的留下，
其他的各归其位。
副标题：
重要、稍后与过滤通知会被自动整理，
需要时再集中查看。
动画
初始画面中央有 4 张混合的通知纸片。
页面下方 / 中部依次出现三个文件夹：
重要消息
稍后处理
已过滤
文件夹必须使用正式首页相同的视觉语言。
然后三张通知分别通过：
translationX
translationY
scale
动画移动到对应文件夹。
当纸片进入文件夹时：
scale 1 → 0.85
alpha 1 → 0
文件夹做一次很轻的：
scale 1 → 1.03 → 1
表示“收纳完成”。
这一幕是整个 onboarding 最关键的动画之一。
用户应当一眼理解：
这个 App 会把不同重要程度的通知分流。

第四幕：准备开始
标题：
把注意力，
留给真正重要的事。
副标题：
从现在开始，让通知更有秩序。
页面中心可以展示一张简化后的 App 首页预览：
今日概览
+
四个文件夹
不必截图，可以直接用现有 View 组件绘制一个简化 miniature。
动画
四个文件夹依次：
translationY 12dp → 0
alpha 0 → 1
间隔约：
60～100ms
最后：
“开始使用”
按钮从：
alpha 0
scale 0.95
进入：
alpha 1
scale 1
点击后：
OnboardingActivity
fade out
↓
MainActivity
fade in
不要突然黑屏切换。
