## 核心证据

关键词检查验证：观察模式保留 9 个样本；自动模式只移除 102、202，保留其余 7 个；保留词、持续通知、分组汇总受保护；移除有系统原因确认；相同 ID 更新后保留重要通知。单入口 Instrumentation 重新运行后仍为 18 项通过。

模型检查验证：两份配置的模型 ID 和 Bearer 凭据独立；JSON 请求与响应结构；重定向、HTTP 失败、超时、超大输入、未知动作和无效 JSON 默认 KEEP；Keystore 加密与两个槽位的 AAD 隔离；未允许远程或受本地保护时不调用模型；单路模型 REMOVE 可触发系统清除；单路 KEEP 不回退关键词删除；即使两路都 REMOVE 且自动开关打开，COMPARE 仍不删除。

延迟回复检查将模型响应挂起，再分别更新通知为紧急内容、修改模型配置、把自动开关关闭再开启、修改保留词，然后释放旧 REMOVE。四种情况均作废旧结果并保留当前通知。

测试发现 Android JsonReader 可接受字符串中的原始换行；客户端已增加字符串词法校验，原始换行和非法转义的回归检查现均通过。系统自动生成的汇总通知不计入发送器的样本 ID 集合；汇总仍受生产保护，未绕过筛选逻辑。

原始通过记录：[关键词设备检查](integration-test.txt)、[模型检查](model-integration-test.txt)。测试结束后恢复关键词、远程关闭、空密钥、观察模式及默认规则。
